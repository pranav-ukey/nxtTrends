# Nxt Trendz – E-commerce Application

A fully responsive e-commerce web application inspired by Amazon and Flipkart, built using React.js. The application allows users to browse products, search, filter, sort, authenticate securely, and manage a shopping cart.

## Features

- User Authentication using JWT
- Protected Routes
- Product Search
- Category Filters
- Sorting Products
- Product Details Page
- Shopping Cart
- Quantity Management
- Remove Individual Items
- Remove All Items
- Responsive Design
